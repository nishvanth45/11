# DUGOUT 11

Cricket Management Simulation — website foundation.

## Run locally
Open `index.html` in any browser. No install or build needed.

## Project structure
```
11/
├── index.html      # Landing page
├── css/style.css   # Styles (theme colours at top)
├── js/main.js      # Button actions (placeholders)
├── assets/logo.svg # Logo / favicon
└── README.md
```

## Live site
Hosted free with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).
